## 1. Goal

Build a **generic, reusable Exchange Online review** for any customer. It's a PowerShell script that connects to a tenant and reads its configuration without changing anything. It then writes a **Markdown review report**, with an optional CSV export for each table. The customer is supplied with the `-CustomerName` parameter, so nothing tenant-specific is hard-coded.

## 2. Decisions made with the user

| Topic | Decision |
|---|---|
| Deliverable | **A report generated by the script.** No manual fill-in template. |
| Report style | **Data only.** It documents current configuration, with no Red/Amber/Green ratings or recommendations. |

| Sensitive output | Reports go to `.\Reports` by default, which `.gitignore` excludes. |

## 4. Script architecture (current draft)

Style follows `Exchange Online/Get-TransportRules.ps1`: comment-based help, `[CmdletBinding()]`, a module check and install, coloured `Write-Host` progress, and disconnect in `finally`.

**Parameters:** `-CustomerName` (mandatory), `-ReviewedBy`, `-ReviewDate`, `-OutputPath` (default `.\Reports`), `-UserPrincipalName`, `-AppId`, `-CertificateThumbprint`, `-Organization`, `-IncludePurview`, `-IncludeMailboxStatistics`, `-IncludeMessageTrace`, `-IncludeGraph`, `-ExportCsv`, `-MaxRows` (default 50), `-DnsServer`.

**Script-scope state:** `$script:Report` (StringBuilder), `$script:CollectionLog`, `$script:Summary`, `$script:CsvData`, `$script:PurviewConnected`/`PurviewError`, `$script:GraphConnected`/`GraphError`, and cached `$script:Mailboxes`/`$script:CasMailboxes`. Mailboxes are fetched once and reused.

**Helper functions (approximate line numbers):**
- `Initialize-ExchangeOnlineModule` (160)
- `Add-Line`, `Add-LogEntry`, `Test-CmdletAvailable`, `Assert-Cmdlet`
- `Convert-ValueToText` and `ConvertTo-MdTable` (220): escape `|`, turn CR/LF into `<br>`, join arrays with `; `, render empty tables as "_None found_", truncate at MaxRows with a note
- `Register-Csv`, `Out-Table`
- `Get-PurviewState`, `Add-PurviewStatusOrThrow`: render Purview sections as Skipped / Not available
- `Invoke-Section` (288): wraps each section and subsection in try/catch. A missing cmdlet or an error writes "Not available: <reason>" and logs it to the appendix. It never aborts the run.
- `Resolve-DnsSafe`, `Get-TxtRecords` (honour `-DnsServer`)
- `Get-SharedMailboxes`, `Get-SharedCasMailboxes` (caching)

**Section functions, in report order:**
1. `Get-OrgConfigSection`: org config, external sender tagging, transport config, Unified Audit Log
2. `Get-RecipientsSection`: counts by RecipientTypeDetails, inactive and soft-deleted mailboxes
3. `Get-MailboxHygieneSection`: holds, archive, audit, audit bypass, forwarding, sign-in-enabled shared/room mailboxes. Mailbox statistics are opt-in.
4. `Get-GroupsSection`: DLs, mail-enabled security groups, dynamic DLs, M365 groups, room lists, groups without owners, groups that accept external senders
5. `Get-DomainsSection`: accepted domains; MX, SPF, DKIM, DMARC (parsed), MTA-STS, TLS-RPT, BIMI; MOERA; ARC
6. `Get-MailFlowSection`: connectors, Enhanced Filtering (On if `EFSkipLastIP` is true or `EFSkipIPs` isn't empty), transport rules, remote domains, journal rules, HVE (`Get-MailUser -HVEAccount`, verified on Learn). Message trace (`Get-MessageTraceV2`) is opt-in.
7. `Get-HybridSection`: on-premises organization, intra-organization connector, migration endpoints and batches
8. `Get-SharingSection`: organization relationships, sharing policies, availability address spaces
9. `Get-ClientAccessSection`: OWA policies, ActiveSync device access rules and org settings, mobile device policies, protocol usage (`Get-EXOCASMailbox`), authentication policies, application access policies
10. `Get-PermissionsSection`: role groups and members, role assignment policies (user roles), custom roles, direct assignments, management scopes, **RBAC for Applications** (`Get-ServicePrincipal` joined to `Get-ManagementRoleAssignment -RoleAssigneeType ServicePrincipal`). The Graph-based Exchange Administrator holders are opt-in.
11. `Get-ThreatProtectionSection`: anti-phishing, anti-spam (inbound, connection filter, outbound), anti-malware, Safe Attachments with `Get-AtpPolicyForO365`, Safe Links, preset and built-in policies, TABL (including spoof entries), advanced delivery (SecOps and phishing simulations), quarantine policies with global settings, priority accounts, user-reported message settings, Teams protection
12. `Get-AlertPoliciesSection` (Purview): `Get-ProtectionAlert`
13. `Get-ComplianceSection`:
    - From EXO: MRM, IRM/OME, journaling
    - From Purview: retention, DLP, sensitivity labels, retention labels
14. `Get-GraphSection` (opt-in): Secure Score and Exchange-related controls
15. `Write-Appendix`: collection log, parameters used, run duration, cmdlet reference

**Output:** `<OutputPath>\EXO-Review_<Customer>_<yyyyMMdd>.md` (UTF-8). With `-ExportCsv`, CSVs go to `<OutputPath>\EXO-Review_<Customer>_<yyyyMMdd>_csv\<Section>.csv`.

## 5. Which session each data source needs

- **Exchange Online session (always):** all EXO recipient, mail-flow, sharing, client-access and RBAC cmdlets, **and all EOP/Defender cmdlets** (anti-phish, anti-spam, malware, Safe Links, Safe Attachments, TABL, quarantine, advanced delivery, preset policies, `Get-EmailTenantSettings`, `Get-ReportSubmissionPolicy`). Also MRM, `Get-IRMConfiguration`, `Get-OMEConfiguration` and `Get-AdminAuditLogConfig`.
- **Security & Compliance / IPPS (only with `-IncludePurview`):** `Get-ProtectionAlert`, `Get-RetentionCompliancePolicy`/`Rule`, `Get-DlpCompliancePolicy`/`Rule`, `Get-Label`, `Get-LabelPolicy`, `Get-ComplianceTag`.
- **Microsoft Graph (only with `-IncludeGraph`):** Secure Score and control profiles, and directory role members (Exchange Administrator). Scopes: `SecurityEvents.Read.All`, `RoleManagement.Read.Directory`, `Directory.Read.All`.

### Permissions (for the README)
- **EXO-only run:** Global Reader at minimum. View-Only Organization Management or Security Reader also work.
- **Purview:** Compliance Administrator, or Security Reader + Compliance Data Administrator, or View-Only Organization Management plus the Purview roles View-Only DLP Compliance Management, View-Only Retention Management and Sensitivity Label Reader.

### Fixes made during the PLAN.md review

1. **Variable-expansion bug (critical):** `"_$state_"` and `"_Not available: $reason_"` interpolated `$state_`/`$reason_` (trailing underscore is a valid name char), rendering empty text. Changed to `"$($state)_"` / `"$($reason)_"`.
2. **`Get-TenantAllowBlockListItems -ListType` is mandatory** (verified on Learn): now loops `Sender, Url, FileHash, IP` per call. `-ListSubType AdvancedDelivery` with `-ListType Url` confirmed for simulation URLs.
3. **`-RoleAssigneeType ServicePrincipal` isn't a documented value** (Learn lists User/SecurityGroup/RoleAssignmentPolicy/ForeignSecurityPrincipal/RoleGroup/LinkedRoleGroup/Computer): kept the fast path but added a fallback that retrieves all assignments and filters on `RoleAssigneeType`/SP `ObjectId`/`AppId`/`RoleAssignee`, logging the fallback to the collection log.
4. **Tenant name/initial domain in the header:** org config and accepted domains are now pre-collected before the header is written (they were previously `$null` because sections ran afterwards).
5. **Mailbox size sorting:** `TotalItemSize` is a display string — the script now parses the "(… bytes)" value into `SizeBytes` and sorts numerically for the top-N table.
6. **Output path:** `Resolve-Path` failure before `try` could throw; restructured to create the folder first.
7. Minor: `$_` shadowing fixed in the role-assignment-policy mailbox count; OWA policy column renamed to `ClassicAttachmentsEnabled`; removed unused variable; `-AppId` now requires `-CertificateThumbprint` + `-Organization`.
8. **Summary counts moved into the header:** recorded an insertion index right after the TOC and `StringBuilder.Insert` the "## Summary counts" block there after all sections run (was appended at the end of the report).
9. **Clickable TOC:** hard-coded numbered list replaced with `- [Title](#anchor)` links generated from a single `$script:SectionTitles` ordered map that also supplies every level-2 heading and the appendix title (titles can't drift). New `ConvertTo-MdAnchor` implements GitHub slug rules (lowercase, strip non `[a-z0-9 \-_]`, spaces → `-`, no collapsing).
10. **Message trace by direction:** new `Get-MessageDirection` classifies each traced message against the accepted domains (Internal / Outbound / Inbound / Other) in addition to the Status table; CSV `MessageTraceByDirection`; summary entries "Messages sampled (inbound)/(outbound)".

Verified on Microsoft Learn: `Get-MessageTraceV2` (StartDate/EndDate, ResultSize ≤ 5000, 10-day window), `Get-EXOMailbox -InactiveMailboxOnly`/`-SoftDeletedMailbox`, `Get-TenantAllowBlockListItems`, `Get-ExoPhishSimOverrideRule`, `Get-ServicePrincipal`, `Get-ManagementRoleAssignment`, `Get-InboundConnector`. Other EF*/quarantine/report-submission properties are accessed defensively (missing properties render empty).
